# Data

This directory documents the data used by the TNBC BRCA1
single-cell RNA-seq analysis pipeline.

## Raw data

The primary dataset is GEO accession GSE161529.

Raw expression matrices are not committed to this repository.
They can be retrieved from the public GEO repository.

## Processed data

Large processed Seurat, CopyKAT, and Monocle3 objects remain
outside version control because of their size.

The repository contains lightweight metadata and documentation
needed to understand data provenance and reproducibility.

See `docs/DATA_AVAILABILITY.md` for dataset information.
