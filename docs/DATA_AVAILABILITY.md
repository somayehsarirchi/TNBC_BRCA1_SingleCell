# Data Availability

The TNBC single-cell RNA-seq dataset analyzed in this project is
publicly available through the Gene Expression Omnibus (GEO).

## Dataset

GEO accession: GSE161529

The analysis includes eight GEO samples:

- GSM4909281
- GSM4909282
- GSM4909283
- GSM4909284
- GSM4909285
- GSM4909286
- GSM4909287
- GSM4909288

The sample-to-accession mapping is maintained in the project
metadata.

Raw expression data are not duplicated in this repository.
Users should retrieve the public dataset directly from GEO.
